# 珠海消防数字化作战训练考核管理平台 - 验收文档

## 1. 项目概述

### 1.1 项目名称

珠海消防数字化作战训练考核管理平台

### 1.2 项目目标

- 实现20家重点单位的三维数字化建模，覆盖"高、低、大、化"四个典型类型
- 构建全流程数字化战训体系，涵盖培训、训练、考评、分析、复盘等环节
- 实现PC端与移动端数据实时同步，确保信息鲜活性
- 提供多维度统计分析功能，为训练、考核、实战提供数据依据
- 满足等级保护第二级和信创适配要求

### 1.3 系统架构

- **展现层**：PC端Web应用、移动端App、大屏展示系统
- **应用层**：三维数字化沙盘推演考评管理子系统、三维数字化预案编制管理子系统、数字化训练考核管理子系统、移动端App服务、统一用户认证与权限管理、统一数据统计分析
- **服务层**：三维模型服务、地图服务、预案服务、训考服务、统计服务、消息推送服务、文件服务、定位服务、全景服务、预警服务
- **数据层**：业务数据库、空间数据库、文件存储、缓存数据库、日志数据库
- **基础设施层**：应用服务器、数据库服务器、文件服务器、备份服务器、定位信标、智能手表、全景相机、无人机
